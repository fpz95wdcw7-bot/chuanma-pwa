# 川麻助手 · 血战到底

手机优先的静态 PWA。四川麻将（血战到底）出牌建议：定缺判断、向听数、有效进牌、攻守排序。

纯前端，没有后端，没有网络请求，装到主屏幕后断网也能用。

改造自 [`xuan9527zz/ai-mahjong-copilot`](https://github.com/xuan9527zz/ai-mahjong-copilot)（原项目是广东麻将 136 张规则）。

## 跟原项目的差异

| 项 | 原项目 | 这里 |
|---|---|---|
| 牌 | 136 张，含字牌 | **108 张**，万筒条各 1-9 |
| 规则 | 广东 `GD-SZ-DEFENSE-V1`，鸡胡仅自摸 | **血战到底**，一炮多响，胡牌后继续 |
| 定缺 | 无 | **有**，缺门没打完不能胡 |
| 番型 | 十三幺、大三元、字一色… | 平胡、对对胡、清一色、七对、龙七对、清对、金钩钓、带幺九、清幺九 |
| 向听 | 34 种牌标准算法 | 27 种 + **缺门扣减** |
| 血战状态 | 有人胡即结束 | 胡的人退出，剩下继续，只剩一家才结束 |

原项目的摄像头识别（`VisionService` + 43KB 牌面图集）**原样保留但未适配川麻牌面**。它是从三张样本图切的模板，作者自己在 README 里写明「严格阈值下 39 张只有 2 张能自动接受」。想用识别得自己重新标模板。

## 出牌决策怎么算

七层优先级，从硬到软，越靠前越不让步：

```
1. 缺门牌绝对优先            规则，不是策略
2. 听牌 > 没听牌             不为番数丢听牌
3. 向听差 ≥ 2                牌效说话
4. 活口差 ≥ 3 倍             番数补不回来
5. 番型方向                  清一色 / 七对 / 对对胡
6. 听口多的优先
7. 策略模式（攻守/进攻/防守）   权重可调
```

**番型方向只在有硬证据时才生效**，判定标准：

| 方向 | 条件 | 效果 |
|---|---|---|
| 七对 | 对子 ≥ 6 组 | 打单张，不拆对子 |
| 对对胡 | 刻子+对子 ≥ 5 组且已有 2 组刻 | 打单张，不拆刻对 |
| 清一色 | 主色 ≥ 9 张且异色 ≤ 4 张 | 打异色，留主色 |

模糊的时候返回 `NORMAL`，完全不干预排序——猜错比不猜更糟。

**听口用枚举算，不估**：27 种牌逐个试，能胡的才收，`remaining` 扣掉手里和场上已见的。所以「听死口只剩 1 张」会如实显示，不会跟「两面 6 张」混为一谈。

**读对手缺门**：川麻定缺后必须先打完缺门，所以一个人**前 5 张**打出的花色基本就是他的缺。前 5 张里某花色占 60% 以上 → 判定缺该门（可信度 85%），40% 以上 → 55%。

实测效果：下家连打 4 张条，判他缺条，打条对他的点炮风险从 8.93% 降到 2.24%。


## 规则实现程度

**已实现**

- 108 张牌集，无字牌
- 定缺：缺门牌必须先打完，有缺牌时不能胡、不算有效进牌
- 出牌推荐：缺门牌强制优先，其余按向听 + 有效进牌 + 相对风险排序
- 向听数（标准型 + 七对）、有效进牌及剩余张数
- 和牌判定：标准型、七对、龙七对、对对胡、清一色、清对、金钩钓、带幺九、清幺九
- 血战到底状态：胡牌者退出、牌局继续、只剩一家才结束
- 一炮多响（多选荣和者）

**没实现**（原项目也没有，或川麻特有但需要房间配置）

- 底分、封顶、番数换算成钱
- 刮风下雨（明杠 / 暗杠 / 杠上炮的分数转移）
- 查大叫、查花猪
- 呼叫转移、包牌
- 杠上花 / 海底捞月 / 抢杠胡的自动判定（番型表里有，但没接事件）

## 关于「实时跟牌」

这个 PWA 的摄像头识别是**拍照后人工核对**，不是实时跟。而且：

**一台手机不可能同时打牌和拍屏**。iOS 切到后台会挂起页面、断掉摄像头流，安卓 Chrome 同样。想在牌局进行中持续识别，只有两条路：

- 第二台设备架在旁边拍
- 线下打实体牌时用第二台设备拍

手机端能做的稳定输入是**手动选牌**：13 张熟练后 5 秒点完，准确率 100%。

## 已知问题

- 语音识别走浏览器自带 API，Chrome 在国内不可用（走 Google 服务器），只有 iPhone Safari 能跑
- 语音解析只认「数字 + 花色」，同音字（同/桶/铜）会漏
- 牌面识别模板是广东牌面，川麻需要重新标定
- 番型表是常见玩法，不同平台规则不一样，别拿去算钱
